Les films et épisodes marqués comme vus dans l'année, mais lus avant l'installation du plugin, sont comptés une fois, pour leur durée complète.

Récapitulatif

Affiche un classement (« top 10 % du serveur ») quand au moins 3 utilisateurs sont actifs. Aucun nom n'est montré.
Chaque utilisateur peut créer un lien, visible sans compte, vers une copie figée de son récapitulatif. Désactiver cette option rend tous les liens inactifs.
Nécessite le plugin File Transformation. Prise en compte au prochain redémarrage.

Bannière d'accueil

Une bannière « Ton JellyWrapped est prêt » s'affiche pendant la période ci-dessous ; chaque utilisateur peut la masquer. Nécessite le plugin File Transformation.
